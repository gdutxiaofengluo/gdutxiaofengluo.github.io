# Xiaofeng Luo Academic Homepage

This repository hosts the academic homepage of Xiaofeng Luo via GitHub Pages.

The site is based on the AcademicPages / Minimal Mistakes Jekyll structure and includes:

- Home / About me
- Publications
- Academic Services
- Awards

To publish, upload all files in this directory to the root of `gdutxiaofengluo.github.io` and enable GitHub Pages from the `main` branch.
